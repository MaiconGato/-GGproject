## 📖 Sobre o projeto

Este repositório contém o site institucional da **GG Project**, desenvolvido para apresentar a empresa, seus serviços e facilitar o contato de novos clientes (empresas, condomínios, residências, escolas e órgãos públicos).

O foco do projeto é transmitir **confiança, profissionalismo e compromisso ambiental**, com uma navegação simples e vários pontos de conversão para pedido de orçamento.

O site foi construído com **HTML, CSS e JavaScript puro**, sem frameworks, priorizando leveza e facilidade de manutenção.

---

## ✨ Seções do site

| Seção | Descrição |
|-------|-----------|
| **Início (Hero)** | Apresentação da empresa e chamada principal para solicitar orçamento |
| **Quem somos** | História, experiência desde 2017 e áreas de atendimento |
| **Missão, Visão e Valores** | Princípios que guiam a empresa |
| **Serviços** | Paisagismo, Manejo Ambiental, Jardins Verticais, Plantio de Árvores, Educação Ambiental e Responsabilidade Técnica |
| **Por que escolher a GG Project** | Qualidade, segurança, sustentabilidade e atendimento personalizado |
| **Números** | Destaques como início das atividades, compromisso com a qualidade e capacitação NR-35 |
| **Projetos** | Galeria com trabalhos realizados |
| **Parceiros** | Empresas e instituições que confiam no trabalho |
| **Segmentos atendidos** | Empresas, condomínios, residências, escolas e órgãos públicos |
| **Contato** | WhatsApp, Instagram, e-mail e formulário de orçamento |

## 🛠️ Funcionalidades

- Layout **responsivo** (desktop, tablet e celular)
- Menu de navegação com rolagem suave entre as seções
- Cards de serviços e diferenciais organizados em grade
- Galeria de projetos realizados
- Formulário de contato para solicitação de orçamento
- Botão flutuante de **WhatsApp**
- Múltiplos botões de chamada para ação (CTA)
- Rodapé com serviços, contatos e áreas de atendimento

---

## 🧰 Tecnologias utilizadas

- **HTML5**: estrutura semântica das páginas
- **CSS3**: estilização, grid, flexbox e responsividade
- **JavaScript**: interações e comportamentos da página
- **Formspree**: envio do formulário de contato
- **Font Awesome**: ícones dos serviços

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/MaiconGato/GG-project.git
```

2. Acesse a pasta do projeto:

```bash
cd GG-project
```

3. Abra o arquivo `index.html` no navegador.

   Opcionalmente, use a extensão **Live Server** do VS Code para atualização automática durante o desenvolvimento.
